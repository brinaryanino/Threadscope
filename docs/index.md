# ThreadScope Documentation

ThreadScope is currently in planning and specification. Application feature work is gated on completing the planning interview, verifying official Threads API feasibility, producing the product and technical specification, and receiving explicit approval from the Owner.

## Authority

1. Explicit Owner decisions and approved changes
2. Accepted ADRs
3. Accepted product and technical specifications
4. `MASTER_PROMPT.md`
5. Verified supporting research

## Current phase

- Release stage: personal-use only
- Delivery form: micro-SaaS web application
- Distribution: one Owner; no private beta or public SaaS in the initial release
- Active work: structured planning interview
- Application implementation: not approved
